# CredResolve Collection Intelligence

## Data Analyst Assignment

This project analyzes collection and recovery operations using data from borrowers, accounts, calls, payments, campaigns, agents, PTPs, field visits, and digital engagement.

The main objective is to understand whether the reported improvement in recovery is genuine, identify the major drivers of performance, and recommend where investment can create the highest business impact.

---

## Business Questions

The analysis focuses on four main questions:

1. What actually happened to recovery performance?
2. What factors contributed to the change?
3. Is the reported 11% month-on-month improvement genuine?
4. Where should investment be prioritized to improve recovery?

---

## Project Components

### 1. Analysis Notebook

The Python notebook contains:

- Data loading
- Data quality checks
- Data cleaning
- Exploratory data analysis
- Recovery analysis
- Driver analysis
- 11% improvement investigation
- Business recommendations

### 2. SQL Analysis

SQL queries are included separately for:

- Risk-segment analysis
- Collection-rate analysis
- High-exposure accounts
- PTP and payment analysis
- Calling activity analysis

### 3. Executive Report

The PDF report summarizes:

- Key findings
- Data-quality issues
- Recovery performance
- Major drivers
- Business recommendations
- Investment considerations

### 4. Power BI Dashboard

The dashboard provides an executive-level view of:

- Recovery performance
- Collection rate
- Outstanding exposure
- Portfolio mix
- Channel performance
- Key operational drivers
- Recommended actions
